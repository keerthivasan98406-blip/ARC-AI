Single-page React application bootstrapped by `index.tsx` into `#root`, with `App.tsx` as the root component that owns all global state (chat sessions, messages, memories, modal flags) and composes child components from `./components/` (`Sidebar`, `ChatContainer`, `StudyHubModal`, `ImageStudioModal`, `CodeVisualizerModal`, `MemoryDrawer`, `AdminDashboardModal`, `FloatingAssistantButton`, `AuroraBackground`). State is persisted to `localStorage` under keys `arc_ai_chat_sessions`, `arc_ai_memories`, and `arc_ai_user_profile`. External model calls are delegated to `services/geminiService.chatWithArcAi`; the Vite dev server proxies `/api` to `http://127.0.0.1:5000` while the production deployment splits concerns via `render.yaml`: a Node.js backend (`server/index.js`) and a static frontend publishing to `./dist`. Types (`Message`, `MessageRole`, `ModelEngine`, `ChatSession`, `MemoryItem`) live in `types.ts` and are imported centrally by `App.tsx`. Tailwind CSS + PostCSS + Autoprefixer provide styling; KaTeX and FontAwesome are loaded as global CSS imports.
