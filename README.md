# AKbot Production Glassmorphic AI OS

Next-Generation AI Assistant OS built with Futuristic Glassmorphism, Deep Space Dark Mode, Multi-Engine Selection, Document Intelligence, Image Generation Studio, Hands-Free Voice Assistant, and Real-Time Web Citations.

## Tech Stack
- **Frontend**: React 18, Vite, TypeScript, Glassmorphic CSS Engine
- **Styling**: Vanilla CSS tokens, Tailwind CSS, KaTeX LaTeX math rendering
- **Multi-Model Intelligence**: OpenAI GPT-5, Claude 3.5 Sonnet, Gemini 1.5 Pro, DeepSeek V3/R1, Llama 3.3 70B

## Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build production bundle
npm run build
```
